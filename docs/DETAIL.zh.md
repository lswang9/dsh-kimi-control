# Kimi 式浏览器接管

让 Agent 的浏览器操作成为可见、可接管的交互，而不只是后台工具调用。

- DSH Desktop 原生浏览器侧栏与真实页面。
- Agent 操作时自动展开侧栏，页面显示“正在操作浏览器”状态芯片与当前动作，Kimi 蓝色细边框标记控制权。
- 用户输入后的“你已接管”状态及一键交还。
- 对话内浏览器卡片采用 Kimi Code 桌面版工具卡片结构：14/20 标题、12/18 目标、8px 图标块、可展开的输入/输出，以及“在侧栏中查看”。
- 保留上游浏览器的 DOM、截图、表单、标签页、登录态和下载能力。

交互层按 Kimi Code 桌面版 3.2.21 浏览器工作台的设计 token 重做（REA 静态逆向）：KMBlue `#1783ff` / `#1a88ff`、8–16 圆角、UI-B2/UI-C1 字号体系、中性 Fills 层、120–180ms 动效。侧栏的标签页、地址栏和历史按钮仍由 DSH 内置的 sidebar-browser 渲染；插件负责接管状态、提示、边框与对话卡片。

桌面端需要同时安装随包提供的 bridge；安装器会备份原文件并支持回滚。Web 端使用独立浏览器窗口，不提供嵌入式原生侧栏。
