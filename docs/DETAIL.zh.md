# Kimi 式浏览器接管

把 DSH 的浏览器侧栏变成 Kimi Code 桌面版的浏览器工作台，并把 Agent 控制状态收进它的工具栏。

- DSH Desktop 浏览器侧栏中的真实页面，使用 Kimi 的 52px 工作台标签条。
- Kimi 浏览器工具栏：返回、前进、刷新/停止、居中域名地址栏（聚焦显示完整 URL，回车导航）、更多菜单。
- 工具栏状态芯片显示 Agent 控制（「正在操作浏览器」）、用户接管（「你已接管」+「交还给 Agent」）和短暂「已完成」反馈。
- 对话内浏览器卡片采用 Kimi 工具卡片结构：24px 图标块、14/20 标题、12/18 目标、状态点、可展开的输入/输出，以及「在侧栏中查看」。
- 保留上游浏览器的 DOM、截图、表单、标签页、登录态和下载能力。

chrome 与交互层按 Kimi Code 桌面版 3.2.21 浏览器工作台的设计 token 重做（REA 静态逆向）：KMBlue `#1783ff` / `#1a88ff`、Bg-Primary `#fff` / `#121212`、8–16 圆角、UI-B2/UI-C1 字号体系、中性 Fills 层、120–180ms 动效。侧栏的标签体与 webview 仍由 DSH 内置 sidebar-browser 提供；插件隐藏其 38px 原生工具栏，按其 DOM 结构注入 Kimi chrome 并复用同一套导航，因此 DSH 升级若改动这些内部结构需要适配。

桌面端需要同时安装随包提供的 bridge；安装器会备份原文件并支持回滚。Web 端使用独立浏览器窗口，不提供嵌入式原生侧栏。
